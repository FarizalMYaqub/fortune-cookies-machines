One original fortune-cookie line written for an AI agent to crack open, entered in make.fun's Fortune Cookies for Machines bounty. The fortune opens like a prophecy about a task the reader has not done yet — then turns: the reader is already holding the finished cookie, because writing this very fortune was the task. The program writes that line to `/output/entry.txt`; there is nothing else to build or run, the contest is decided on the writing alone.

## Run it

```sh
python3 main.py
```
